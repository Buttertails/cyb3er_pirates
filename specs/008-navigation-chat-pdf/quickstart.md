# Focused validation

1. Sign in. Start live chat, visit Account, and return to Assistant. Previous messages remain and no new welcome exchange appears.
2. Upload a small selectable-text PDF mentioning a supported procedure. Chat shows filename, excerpt, and procedure confirmation in one upload action.
3. Upload an image-only, corrupt, and oversized PDF separately. Each yields a specific error and leaves chat intact.
4. Confirm the procedure, estimate, change network, ask benefits, and find dentists. No restart occurs; figures match the backend.
5. Check phone-width navigation and verify recent-visit behavior is unchanged.

Run focused automated checks for PDF/chat and navigation, then `npm run build` before delivery.
